Restart DPD dan DCP untuk windows yang digunakan pada komputer admin support
Untuk di DPD dan DPD jalankan program client yang bisa diambil di https://github.com/makassardcg030-sketch/ClientRestart
setting di client:
  klik kanan di tray kanan bawah (lingkaran hijau)
  tentukan file PGDCNewPicking.exe lalu save agar close program bisa bekerja
  lakukan hal yang sama untuk DCP
Jika ada error saat jalankan program, cari sendiri solusinya karena di sini sudah work
kecuali alurnya yang tidak sesuai, bisa info ke Kami support dc Mks
